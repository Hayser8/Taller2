# Capturas pendientes

La evidencia textual de las dos ejecuciones está en
[`../evidence/terminal-results.md`](../evidence/terminal-results.md). Para
completar las capturas PNG solicitadas, abre Terminal y:

1. Ejecuta `source .venv/bin/activate`, `python --version` y
   `python -m taller2_ml.pipeline`; guarda la captura como
   `python-venv.png` en esta carpeta.
2. Con Conda instalado, ejecuta `conda create --file environment.yml`,
   `conda activate taller2-ml`, `python --version` y
   `python -m taller2_ml.pipeline`; guarda la captura como `conda.png` aquí.
